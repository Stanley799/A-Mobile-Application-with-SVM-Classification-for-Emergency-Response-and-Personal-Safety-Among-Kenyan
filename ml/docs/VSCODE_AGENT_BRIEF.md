# Project brief for the coding agent (read fully before changing anything)

## 1. What this project is
Capstone: "A Mobile Application with SVM Classification for Emergency Response and Personal Safety Among Kenyan Residents"
(Strathmore University, student Oduor Stanley Otieno, 166601, supervisor Mr. Patrick Shabaya). Flutter + Firebase app.
The `ml/` folder is the triage and dispatch brain. It is DECISION SUPPORT: it suggests a priority (Low/Medium/High); the
resident confirms. It never replaces 922 (National Ambulance Dispatch Centre) or a clinician.

## 2. Single source of truth (do not duplicate rules in code)
- `ml/schema/triage_schema.json` v3.0.0: questions, categories, subtypes, weights, floors F01-F10, routing, briefing, hotlines.
- `ml/scripts/triage_core.py` loads it. Dart constants are GENERATED by `scripts/generate_dart.py`. Never hand-edit `ml/dart/*`.
- If you change the schema, bump the version, re-run `py scripts\run_all.py`, and keep every test green.

## 3. Pipeline (run from the `ml` folder on Windows: `py scripts\<name>.py`)
generate_synthetic_data -> train_classifier -> build_decision_table -> test_combinations (16,740 combinations, must PASS)
-> test_dispatch_logic (12 tests) -> train_text_classifier -> evaluate_text -> generate_dart. `run_all.py` runs them all.
Text path: see docs/text_triage_architecture.md.
Layers: strict validation -> rule floors -> SVM-RBF -> safety bias (P(High)>=0.35) -> monotone repair -> human-review flag -> resident confirms.
Runtime uses the compiled `models/decision_table.json` (offline, inspectable). Python model is for training/audit.

## 4. Non-negotiable rules
1. Safety floors are never lowered. A worse answer must never lower the priority (0 monotonic violations).
2. NEVER write or guess Swahili/Sheng words. The owner fills `schema/lexicon_user.json` and the CSVs himself with native speakers.
3. Unverified hotlines (999, 112, 116) stay off. Verified only: 922 and 1195.
4. Confidential handling: sexual_violence and domestic_violence never auto-notify trusted contacts and share no free text.
5. Privacy: resident name/phone released to the responder only after acceptance. Never send contacts, email, home address, device id.
6. Do not invent accuracy numbers. The English dev set (43 messages) is a regression test, NOT accuracy evidence.
7. Do not add dependencies without asking. Python 3.14, scikit-learn >=1.9,<1.11.
